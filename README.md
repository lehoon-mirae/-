# 자산운용부 일보 대시보드 (Streamlit)

업로드한 일보 양식 엑셀을 그대로 화면에 띄우고, 월말 일보를 누적해
자산구분 대분류별 전월대비 손익 변동을 비교·시각화하는 로컬 대시보드입니다.

## 실행 방법

이 폴더의 모든 파일을 같은 위치에 두고, 터미널(명령 프롬프트)에서:

```
pip install -r requirements.txt
streamlit run app.py
```

브라우저가 자동으로 열립니다. (열리지 않으면 http://localhost:8501)

## 포함 파일

| 파일 | 설명 |
|------|------|
| `app.py` | 대시보드 본체 |
| `report_parser.py` | 일보 양식(2단 헤더·계층형 행) 전용 파서 |
| `make_samples.py` | 월말 샘플 일보 생성 스크립트 |
| `requirements.txt` | 필요한 패키지 목록 |
| `일보_20260331.xlsx` ~ `일보_20260520.xlsx` | 동작 확인용 샘플 (임의 수치) |

## 사용 방법

1. 사이드바 **① 일보 파일 불러오기**에서 일보 엑셀을 업로드합니다.
   - 여러 개를 한 번에 올리면 기준일별로 적재되어 전월대비 비교가 됩니다.
   - 업로드가 없으면 같은 폴더의 샘플 일보가 표시됩니다.
2. 탭에서 확인합니다.
   - **원본 일보**: 선택한 기준일의 일보를 양식 그대로 표시 (합계·총합계 행 강조)
   - **요약 대시보드**: 최신일 총 NAV·당기손익, 자산배분, 상세손익 구성
   - **전월대비 비교**: 지표 선택 → 자산구분 대분류별 월 칼럼 비교표 + 차트

## 파일명 규칙 (중요)

기준일을 파일명에서 자동 인식합니다. **`일보_YYYYMMDD.xlsx`** 형식으로 저장하세요.
예) `일보_20260430.xlsx` → 기준일 2026-04-30

월말 일보를 이 규칙으로 모아 두고 함께 업로드하면 전월대비 비교가 동작합니다.

## 양식이 바뀌면

`report_parser.py` 상단의 `CLEAN_COLS`(컬럼 매핑)와 행 분류 규칙(`_row_type`)이
업로드하신 일보 양식 기준으로 작성되어 있습니다. 양식의 컬럼 구성이나
헤더 단수가 바뀌면 이 부분을 수정해야 합니다.
